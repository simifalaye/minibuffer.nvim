Introduction                                                  *minibuffer.intro*

This plugin provides a unified and interactive buffer interface for:
 - Displaying timely interactive content
 - Taking user input while providing suggestions interactively
 - Interactive selection

Configuration                                                *minibuffer.config*


To configure minibuffer, set the variable `vim.g.minibuffer`,
which is a |minibuffer.Opts| table, in your Neovim configuration.

Example:

>lua
---@type minibuffer.Opts
vim.g.minibuffer = {
   ---@type minibuffer.cmd.Opts
   cmd = {
     -- ...
   },
 }
<

Notes:

 - `vim.g.minibuffer` can also be a function that returns a |minibuffer.Opts| table.


minibuffer.cmd.Opts                                        *minibuffer.cmd.Opts*

    Fields: ~
        {enabled?}         (boolean)  Enable command line wildmenu replacement through the minibuffer
        {autotrigger?}     (boolean)  Display completion suggestions as you type
        {dynamic_height?}  (boolean)  Whether the completion window should shrink as items disappear.
        {max_height?}      (integer)  Maximum height when using the command line


minibuffer.Opts                                                *minibuffer.Opts*

    Fields: ~
        {dynamic_window_resize?}  (boolean)              Shrink other windows when the minibuffer is expanded
        {cmd?}                    (minibuffer.cmd.Opts)  Opts for cmdline
